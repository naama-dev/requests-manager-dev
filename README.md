# 9. תכנון עבודה וחלוקה למשימות

## מטרת התכנון

את העבודה חילקתי למשימות לפי שלבי הפיתוח, החל מניתוח הדרישות ותכנון מבנה המערכת ועד למימוש, בדיקות ותיעוד. המטרה הייתה להתקדם בצורה מסודרת, כאשר כל משימה מגדירה מה צריך לבצע, מה התוצר המצופה ממנה ואילו משימות קודמות נדרשות לצורך השלמתה.

התכנון כולל את פיתוח השרת ב־.NET, העבודה מול מסד הנתונים, בניית ממשק Angular, טיפול בעדכונים מתחרים, שמירת היסטוריית שינויים, פעולות Bulk, בדיקות אוטומטיות ובדיקות ביצועים.

## סדר ביצוע ותלויות בין המשימות

העבודה מתחילה בניתוח הדרישות ובתכנון מסד הנתונים והארכיטקטורה. לאחר מכן מוקם הפרויקט, מוגדר החיבור למסד הנתונים ומפותחים המודלים ושכבת הגישה לנתונים.

על בסיס שכבות אלה מפותחות פעולות ה־API, ובהן שליפת פניות, עדכון סטטוס, היסטוריית שינויים, פעולת Bulk ונתוני סיכום. לאחר שהפעולות המרכזיות זמינות, ניתן לחבר אליהן את ממשק Angular ולממש את החיפוש, הסינון והטיפול במצבי טעינה ושגיאה.

יצירת נתוני הבדיקה נדרשת לצורך בדיקת המערכת בהיקף הנתונים שהוגדר במבדק. לאחר השלמת פעולות הליבה ניתן לבצע בדיקות אוטומטיות ובדיקות ביצועים, לבחון את יעילות השאילתות ואת התאמת האינדקסים ולבצע תיקונים לפי הממצאים.

בשלב האחרון משלימים את התיעוד ומוודאים שניתן להריץ את המערכת ולהציג את התרחישים המרכזיים.

## סיכום

חלוקת העבודה למשימות מאפשרת לעקוב אחר ההתקדמות, להבין אילו שלבים תלויים זה בזה ולוודא שכל דרישות המבדק מקבלות מענה. לכל משימה הוגדרו פעולות לביצוע ותוצר מצופה, כדי שניתן יהיה לבדוק את השלמתה.

התכנון כולל לא רק את כתיבת הקוד, אלא גם יצירת נתוני בדיקה, בדיקות אוטומטיות, בדיקות ביצועים ותיעוד ההחלטות הטכנולוגיות. כך ניתן לבחון את המערכת מבחינת תקינות, אמינות, ביצועים ויכולת תחזוקה.
